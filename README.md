# ATM Machine Manual Testing Project

## Project Overview
This is a beginner-friendly manual software testing portfolio project for an **ATM simulator**. It documents test scenarios for card validation, PIN authentication, balance enquiry, cash withdrawal, transaction limits, mini statements, receipts, and session termination.

> **Important:** This repository contains test documentation, not a working ATM application. Execute the cases only in a simulator or authorized test environment. Never use real bank cards, PINs, accounts, or ATMs for these exercises.

## Objective
- Prepare test scenarios and test cases.
- Cover positive, negative, and boundary-value scenarios.
- Record actual results and pass/fail status.
- Document reproducible defects.
- Produce a test execution summary.

## Scope
1. Card validation
2. PIN authentication
3. Balance enquiry
4. Cash withdrawal
5. Withdrawal limits and denominations
6. Mini statement
7. Receipt generation
8. Session timeout
9. Session termination and card ejection

## Testing Types
- Manual testing

- Negative testing

## Test Environment
Use a dedicated ATM simulator or training application with fictional test data. Actual available features and rules depend on the simulator.

## How to Use
1. Review `Test-Plan.md` and `Test-Data.md`.
2. Open `Test-Cases.md` or import `Test-Cases.csv` into Excel/Google Sheets.
3. Execute each applicable test in an authorized simulator.
4. Record the observed result in `Test-Execution-Report.csv`.
5. If a failure is reproducible, create a report using `Bug-Report-Template.md`.
6. Update `Test-Summary.md` using the actual execution data.
